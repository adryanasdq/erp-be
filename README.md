# Enterprise Resource Planning (ERP)

This project demonstrates what I have been working previously. Not all features are completed, but the main idea is. Feel free to contact me if you want to try this out!

Tech Summary:
- Language: Python 3.12+
- Web Framework: FastAPI (with standard dependencies for development)
- Database: PostgreSQL
- ORM: SQLModel (built on SQLAlchemy 2.0+)
- Migrations: Alembic
- Authentication: JWT (via PyJWT), password hashing (via Passlib)
- ASGI Server: Uvicorn
- ID Generation: CUID2
- Linting/Formatting: Ruff
